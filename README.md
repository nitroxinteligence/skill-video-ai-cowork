# Agente de Roteiros & Vídeos Curtos (`skill-video-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Vídeo Curto & Reels** com Agentes de IA.

## O que este agente faz

Escreve roteiros de Reels, Shorts e vídeos comerciais com ganchos fortes nos primeiros segundos e CTA direto.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-video-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Informe o assunto do vídeo, o tempo desejado (30s a 60s) e a ação final. O agente entrega aberturas de retenção, falas curtas e marcações visuais prontas para gravar.
